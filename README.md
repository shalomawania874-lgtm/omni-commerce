# OmniCommerce

AI-native all-in-one commerce platform.

## Included
- Merchant authentication via Supabase
- Persistent products, customers and orders
- Published storefronts
- Real order capture
- Product/variant/collection/order/discount/shipping/review/page/analytics/email/return/gift-card/redirect data model
- First-party analytics foundation
- Mobile-first admin
- AI operator UX
- Composio integration architecture
- Static deployment compatible with Vercel
- MIT licensed

## Deployment
The live build uses Supabase for persistence and can run on Vercel's free hosting. Payment processors are intentionally connector-based: card/mobile-money processing requires the merchant's own authorized provider account; the platform does not fake successful payments.

## Competitive scope
The product is designed around the documented feature sets of Shopify and Amboras: storefronts, catalog, variants, inventory foundations, orders, customers, promotions, reviews, shipping, returns, analytics, SEO foundations, subscriptions/marketing data models, AI-assisted operations, first-party analytics, A/B testing foundations, migration-ready data structures, and multichannel integration points.
